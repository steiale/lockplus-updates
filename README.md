# lockplus-updates

Update feed for **LockPlus** (native macOS app). Served via GitHub Pages:

- Feed: `https://steiale.github.io/lockplus-updates/appcast.xml`

Every update is signed with LockPlus's EdDSA key; the app rejects anything else. This repository only holds the
appcast (and release notes); update archives are attached to GitHub Releases. Do not edit `appcast.xml` by hand —
it is generated and signed by the release tooling.
